## Trocar por uma foto nova

Duas opções:

1. **Mais simples:** substitua o arquivo mantendo exatamente o mesmo
   nome (`maryelle-hero.jpg` ou `maryelle-sobre.jpg`). Nada mais precisa
   mudar.
2. **Nome diferente ou outra seção:** no `index.html`, ache a tag
   `<img>` correspondente (dentro de `.hero-visual` ou `.sobre-visual`)
   e troque o `src`.

Fotos com proporção próxima de **4:5** (retrato) encaixam melhor nos
espaços já reservados. Se a foto vier muito pesada (celulares modernos
costumam gerar arquivos de vários MB), vale redimensionar para no máximo
~1200px de largura antes de subir, para manter o site rápido.
